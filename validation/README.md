# Release verification records

`summary.json` gives the combined packaging checks. `baselines.json` records the circuit comparison and seven two-update benchmark executions. `training.json` records three two-update training executions, CLI checks and archived-data audits. `flow_checkpoints.json` records regeneration of final flow predictions and their errors.

The command records retain the machine paths used during verification, before the package was renamed for GitHub. Executable instructions use relative paths in the repository README.
