# Training experiments used in the revised manuscript

This part of the GitHub release contains the final training code, configurations and saved results used in Tables 7–11 and the accompanying reviewer responses. Run the commands below from `supplementary/` with the Python environment described in the top-level README.

## Saved results and rerun outputs

Published records remain in each experiment's `results/` or `runs/` directory. `jobs_training.json` provides 94 independent jobs for the central experiment runner. Script paths and output paths are relative to `supplementary/`; `{output}` is replaced by the selected result path. Fresh results are written under `rerun_results/`, including all checkpoint and prediction files generated by the fixed-weight experiment.

Each job records every exposed command-line setting. The `fixed_configuration` field records constants specified directly in the source, including grid sizes and observation counts. The learning-rate sweep uses `1e-4`, `5e-4`, `1e-3`, `2e-3`, `5e-3` and `1e-2`. Ansatz comparisons use 600 updates; the remaining sensitivity comparisons use 500 updates. Core comparisons use 1,000 updates and three seeds.

The archived Table 7 runs used the RTX 4070. Fixed-weight runs used CPU, float32 and one PyTorch thread per process. The other neural scripts select CUDA when available and otherwise select CPU. Timing records describe their recorded machine, selected device and execution conditions.

### Example: one core training run

```bash
python reviewer11_experiments/elastostatic_forward.py --model qpinn --bc hard --sampling uniform --weighting fixed --seed 0 --steps 1000 --lr 0.005 --width 5 --qubits 5 --n 1 --out rerun_results/reviewer11_experiments/results/elastostatic_core/qpinn_hard_uniform_fixed_seed0.json
```

### Example: one ansatz run

```bash
python reviewer11_experiments/ansatz_sensitivity.py --ansatz ryrz --seed 0 --steps 600 --out rerun_results/reviewer11_experiments/results/ansatz/ryrz_seed0.json
```

### Example: one fixed-weight run

```bash
python reviewer_supplement_20261007/fixed_weights/train_fixed_weights.py run --model qpinn --weight 10 --seed 0 --steps 1000 --out rerun_results/reviewer_supplement_20261007/fixed_weights/runs/qpinn_lambdaBC10_seed0/result.json
```

The fixed-weight command saves `config.json`, `training_points.npy`, `predictions.npz` and `checkpoint.pt` beside the selected result JSON. A complete fresh 18-run matrix can also be produced with:

```bash
python reviewer_supplement_20261007/fixed_weights/train_fixed_weights.py --output-root rerun_results/reviewer_supplement_20261007/fixed_weights all --workers 1
```

## Recalculate published tables and diagnostics

Summarize the archived results, including the final adjoint FEM baseline:

```bash
python reviewer11_experiments/summarize_final_training.py --results reviewer11_experiments/results --out rerun_results/final_training_summary.json
```

The supplied `reviewer11_experiments/results/final_training_summary.json` was calculated from the published records. Means and standard deviations use the actual seeds in each group; standard deviations are sample SD with `ddof = 1`. Fields ending in `_percent` use percentages; archived `rel_l2` values use fractions.

For Table 11, reconstruct the 100-element FEM displacement using the saved converged coefficients, linearly interpolate to the same 201-point evaluation grid, and calculate the relative Euclidean error against `sin(pi*x)`. This gives a displacement error of **0.006522386045490473%** for the final adjoint result. The summary contains this calculation and the neural coefficient, displacement and timing statistics.

Audit the archived full-loss gradients:

```bash
python reviewer_supplement_20261007/gradient_audit/audit_training_gradients.py --source-root reviewer11_experiments --outdir rerun_results/gradient_audit
```

The audit reads 30 core runs and ten circuit-size runs, yielding 390 stored checkpoints. Quantum/classical gradients describe the state before the labeled update; prediction statistics describe the state after that update. For the adaptive-weighting checkpoint, the current weighted objective is reconstructed from `wf`, `lf`, `wb` and `lb`. The archive preserves the logged scalar and the reconstructed objective. Table 9 pairs the circuit-only initialization diagnostic at `n = 3` with the full-model training diagnostic at `n = 1`.

Audit the archived fixed-weight records:

```bash
python reviewer_supplement_20261007/fixed_weights/audit_results.py --root reviewer_supplement_20261007/fixed_weights --outdir rerun_results/fixed_weights_audit
```

After rerunning all fixed-weight jobs, create their summary and audit with:

```bash
python reviewer_supplement_20261007/fixed_weights/train_fixed_weights.py --output-root rerun_results/reviewer_supplement_20261007/fixed_weights summarize
python reviewer_supplement_20261007/fixed_weights/audit_results.py --root rerun_results/reviewer_supplement_20261007/fixed_weights --outdir rerun_results/fixed_weights_audit
```

The gradient audit reads JSON histories. The fixed-weight audit additionally verifies prediction arrays and saved checkpoint hashes. These records are included in the release.
